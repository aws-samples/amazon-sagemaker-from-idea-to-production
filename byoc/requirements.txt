# CPU-only PyTorch wheel. sagemaker-serve (pulled transitively by sagemaker-train
# and friends) depends on torch. Without this extra index, pip resolves to the
# default PyPI torch build, which drags in ~3 GB of CUDA libraries we do not
# need on CPU training/inference instances. The CPU wheel is ~200 MB.
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.13.0+cpu
